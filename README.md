# Amazon Sales Dashboard

A data analysis dashboard project built using Python, Pandas, and Matplotlib.

## Features
- CSV data analysis
- Sales insights visualization
- Ratings trend analysis
- Multiple dashboard charts
- Data plotting with Matplotlib

## Technologies Used
- Python
- Pandas
- Matplotlib

## Files Included
- main.py
- amazon.csv
- Output.png

## Output
This project generates dashboard visualizations for Amazon sales data analysis.
